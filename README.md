# LeetCode Spaced Repetition Extension

## Installation Instructions

1.  Open Chrome and navigate to `chrome://extensions`.
2.  Enable **Developer mode** in the top right corner.
3.  Click **Load unpacked**.
4.  Select the `extension` folder in this project.
5.  Go to LeetCode and solve a problem!

## Features

- **Automatic Tracking**: Detects when you see the "Accepted" message on a problem page.
- **Spaced Repetition**: Schedules revisions at 1, 3, 7, 21, 45, 90 days.
- **Popup Dashboard**: Click the extension icon to see what's due today.
- **Random Review**: Occasionally suggests a random previously solved problem to keep patterns fresh.

## Privacy

All data is stored locally in your browser (`chrome.storage.local`). No external servers are used.
